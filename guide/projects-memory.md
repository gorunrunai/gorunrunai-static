# Projects and memory

## Projects

A project groups related chats with shared **instructions** ("answer as a patient math tutor") and **knowledge files** (a handbook, notes, a spreadsheet). Every chat in the project can use them. Create one with **Projects** in the sidebar.

## Memory

Say "remember that I'm vegetarian" or "remember my son's school is Lincoln Elementary", and it will use that in later chats. Review, edit or delete memories in **Settings → Memory**, or turn memory off entirely. Incognito chats never use memory.

## Styles and custom instructions

In **Settings → Styles**, choose how it writes (concise, explanatory, formal), or create your own style from a writing sample. **Settings → General** holds instructions that apply to every chat.
